
# 🤝 Contribution Guidelines

Thank you for considering contributing to **C-Utilities Toolkit**!

To keep the project clean and consistent, follow these rules:

---

## 1️⃣ Fork the repository
Create your own copy.

## 2️⃣ Create a new branch
Use meaningful names:
- feature/add-reverse-function
- fix/uppercase-null-bug
- docs/improve-readme

## 3️⃣ Commit message rules
- Use short, clear messages.
- Examples:
  - `Fix: handle NULL input in to_uppercase()`
  - `Add: reverse_string() implementation`
  - `Docs: update build instructions`

## 4️⃣ Code Style Rules
- Use 4 spaces indentation.
- Use meaningful variable names.
- Add comments for non-trivial logic.
- Header declarations go in `/include`.
- Implementations go in `/src`.

## 5️⃣ Every function must include:
- A description comment
- Parameter explanation
- Return value explanation
- At least one test in `/test`

## 6️⃣ Submit a Pull Request
Follow the **Pull Request Template**.

## 7️⃣ Wait for review
Your classmates will review your PR before merge.

---

## 💡 New Contributors Can Work On:

Beginner tasks:
- Add new math functions
- Add new string utilities
- Improve documentation
- Update CONTRIBUTORS list

Intermediate tasks:
- Improve test coverage
- Add error handling to file utilities
- Optimize existing functions

Advanced tasks:
- Add CI in GitHub Actions
- Create modular build system (Makefile)

Happy coding! 🙂
